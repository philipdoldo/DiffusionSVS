Simple implementation of Singing Voice Synthesis (SVS) using diffusion and flow models. The original goal of the repo was to replicate DiffSinger https://arxiv.org/abs/2105.02446 as a pedagogical exercise. After successfully replicating DiffSinger (not a 100% faithful replication, for example I chose to use RoPE, but close enough), I started experimenting with different approaches (e.g. DiT instead of WaveNet, flow model instead of the original diffusion approach in DiffSinger, etc.). This repo handles binarizing the data, dataloading, DDP training, etc.
